# Twitch 文化與梗百科

Twitch 平台常見 emote、梗語、黑話的詞條集合。每個檔案對應一個詞條，
`keys:` 列出觸發匹配的關鍵字，命中後該段內容會注入 AI 系統提示。

## 組織慣例

- 扁平結構，每個 `*.md` 對應一個獨立詞條，無子目錄。
- 檔名 = emote / 詞條的小寫 ASCII 表示（`kappa.md`、`pogchamp.md`、
  `f-in-chat.md`）。
- `keys` 列出所有變體拼寫（如 PogChamp 詞條的 keys 含
  `pogchamp, pog, poggers, pogu, komodohype`）。
