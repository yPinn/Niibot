# 叉滴娛樂 XD.ent

台灣規模最大的 Twitch 實況主經紀品牌（XD Entertainment）。每個 entry
對應一塊資訊主題，查詢命中對應關鍵字時注入 AI 系統提示。

## 組織慣例

- `basics.md` / `positioning.md` / `roster.md` / `ecosystem.md` / `notes.md` ─
  品牌層級資訊與背景。
- `people/<name>.md` ─ 人物 profile（身分、現職、暱稱）。生平簡介，
  完整事件始末另置 `events/`。
- `events/<YYYY>-<slug>.md` ─ 重大事件完整始末（背景、經過、後續、
  證實狀態）；檔名 `<YYYY>-<who/what>-<topic>` 便於排序。
- 跨人事件（例如創辦事件涉及多位創辦人）放 `events/`，個人事件
  路徑亦可用 `events/<who>-<topic>.md` 區隔。
