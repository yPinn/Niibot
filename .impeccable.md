# Impeccable — Project Design Context

## Design Context

### Users
Twitch broadcasters (streamers) running Niibot on their channel. They use the
dashboard to configure and monitor a Twitch + Discord bot — commands, timers,
events, loyalty-point redemptions, moderation, and channel analytics. Multi-tenant
(one tenant per broadcaster channel). There are also public, read-only pages
(e.g. a channel's command list) that a streamer's viewers land on. Niibot is a
personal project / feature collection, not a commercial product — treat
competitor/pricing framing as reference only.

### Brand Personality
Twitch-adjacent and approachable: **friendly, warm, energetic** — never corporate
or clinical. The type pairing sets the tone: **Gen Sen Rounded** (rounded, soft)
for display + **Fira Code** for mono/technical text. Brand colour is Twitch
purple `#9146FF` ≈ `oklch(0.54 0.27 293)`.

### Aesthetic Direction
- **Dark-first.** The dark theme mirrors Twitch's own surfaces
  (`#0E0E10 / #18181B / #1F1F23`) and is the primary experience.
- **Light theme is secondary but must be presentable** — clean, readable, not
  embarrassing. Neutrals are tinted toward the brand hue (293) for a soft
  lavender-white rather than a dead gray; cards are near-white, not pure white.
- Token-driven: every colour, size, space, duration and easing is a CSS custom
  property in `frontend/src/index.css` (`@theme inline` + `:root` / `.dark`).
  Components consume semantic tokens, not raw Tailwind values.
- Anti-references: AI-slop cyan-on-dark, purple→blue gradients, glassmorphism,
  glowing accents, gradient text on metrics, identical card grids.

### Design Principles
1. **Contrast is non-negotiable.** Every text / UI pair meets WCAG AA
   (4.5:1 text, 3:1 large/UI). Status and chat-role colours are deepened
   specifically for light mode so they pass as text on white/card.
2. **Tint the neutrals.** No pure gray, no pure black, no pure white for large
   areas — everything carries a whisper of hue 293.
3. **The brand purple is an accent, used sparingly** — primary actions, focus
   rings, the active nav item. Not sprayed everywhere.
4. **Motion is one coordinated system.** Collapse/expand and page transitions
   use `--duration-slow` + `--ease-default`; `prefers-reduced-motion` disables
   all of it globally.
5. **Semantic tokens over ad-hoc values.** New UI reaches for `text-sub`,
   `gap-section`, `p-card`, `text-status-*` — never `text-sm`, `gap-4`,
   `text-red-500`.
